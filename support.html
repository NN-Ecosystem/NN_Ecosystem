Core Factory Support

For Core Factory installation, account, Marketplace, Core Credit, payment, or ecosystem-item support, contact NN Ecosystem by email.

When contacting support

Please include the Core Factory version, a short description of the issue, and any non-sensitive error message or order/reference identifier that helps identify the request.

Do not send passwords, full payment-card numbers, card security codes, private keys, access tokens, or other secret credentials.

Core Credit and payment support

For a duplicate, incorrect, failed, or undelivered Core Credit purchase, include the account email and the relevant Core order or payment-provider transaction reference. Refund requests are handled under the published Refund Policy and applicable mandatory consumer rights.
